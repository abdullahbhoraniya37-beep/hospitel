# Vishwas Hospital — Premium Hospital Website

A white premium 3D/glassmorphism hospital website built with HTML, CSS and vanilla JavaScript.

## Included
- Public patient/user panel
- Admin CMS panel
- Doctor management: primary, supportive, visiting, consultant, specialist
- Doctor photo, degree, specialization, experience, biography, schedule
- Diseases/conditions with photo upload
- Treatments with photo upload
- Departments with photo upload
- Hero photo/video upload and activation
- Gallery photo/video upload
- Health articles with photo upload
- Google Maps URL/address support
- Hospital logo upload
- Instagram/Facebook/YouTube links
- WhatsApp button (call button removed)
- Date-specific doctor slots
- One patient per slot enforcement
- Cancelled appointment releases the slot
- Admin confirmation workflow
- Appointment ID and printable appointment letter
- Patient appointment lookup by ID + phone
- JSON backup/import
- Responsive desktop/tablet/mobile design

## How to run
Open `index.html` in a modern browser. No build step is required.

## Important
This standalone version stores data in the browser's localStorage. Large videos can exceed browser storage limits. For a real multi-device hospital deployment, connect a secure backend/database and cloud media storage.
